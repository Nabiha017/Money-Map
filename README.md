## About MoneyMap
MoneyMap is a personal finance management web application that helps users track income, expenses, budgets and savings goals. Unlike basic budget trackers that only record and display transactions, MoneyMap analyzes spending behavior and provides personalized insights to help users make better financial decisions.

## Key Features
- Secure user registration and login using JWT authentication.
- Income and expense tracking with expense categorization.
- Monthly budget management and monitoring.
- Savings goals with progress tracking.
- Dashboard with financial summaries and visual charts.
- Spending pattern and trend analysis.
- Financial leak detection for repeated small expenses.
- Detection of unusual spending patterns.
- Future spending prediction using historical data.
- Personalized spending insights and recommendations.
- What-If Simulator to understand how planned purchases may affect budgets and savings goals.

### AI & Machine Learning
MoneyMap uses Python, Scikit-learn and Pandas for financial data analysis and machine-learning features. It analyzes historical spending to identify patterns, detect unusual expenses, predict future spending and generate personalized insights.

### What Makes MoneyMap Different?

Traditional budget trackers mainly follow:
**Record → Categorize → Display**

MoneyMap focuses on:
**Track → Analyze → Detect → Predict → Recommend → Decide**
This makes MoneyMap more than an expense tracker. It helps users understand their spending habits, identify financial leaks, predict future expenses and understand how spending decisions can affect their financial goals.

## Technology Stack
- Frontend: React.js
- Backend: Python, FastAPI
- Database: MongoDB Atlas
- AI/ML: Python, Scikit-learn, Pandas
- Authentication: JWT
- APIs: REST API
- Visualization: Recharts / Chart.js
- Version Control: Git & GitHub

## How It Works
Users enter their financial information through the React frontend. The data is processed by the FastAPI backend and stored in MongoDB Atlas. The financial data is then used for analytics and AI/ML processing, with the results displayed through the dashboard as insights, predictions and recommendations.

### Project Goal

MoneyMap aims to help users move from simply tracking their money to actually understanding it and making smarter everyday financial decisions.
